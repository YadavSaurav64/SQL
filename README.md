# SQL & MySQL Practice

A structured, hands-on repository documenting my journey of learning **SQL with MySQL**, from fundamental database operations to advanced SQL queries and interview-level problem solving.

The goal is to build strong SQL fundamentals, develop practical database skills, and become confident writing, understanding, debugging, and optimizing SQL queries.

## 🎯 Learning Objectives

- Master SQL fundamentals and MySQL syntax.
- Understand relational databases, tables, relationships, and constraints.
- Write complex queries using joins, subqueries, CTEs, and window functions.
- Work with aggregate functions, grouping, sorting, and filtering.
- Understand database normalization, indexes, and query optimization.
- Practice real-world database scenarios and interview questions.
- Learn how SQL integrates with backend development.

- Understand the output and execution logic of every query.
- Experiment with different approaches and edge cases.
- Progressively solve more complex interview-level problems.
- Maintain clean, organized, and reusable SQL scripts.
